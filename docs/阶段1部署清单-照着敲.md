# 部署清单 · 照着敲（宝塔面板 + MySQL + Web 安装向导）

> 目标：把养元汇工作台部署到你自己的服务器。数据库连接、建表、建管理员**全部在网页后台一键完成**，不用手改配置文件。
> 全程你在自己服务器操作，我不需要远程权限。按顺序执行即可。

---

## 第 0 步：准备源码

把整个工作区目录上传到服务器，比如 `/srv/yangyuanhui-src`（包含 `api/`、`web/`、`scripts/`、`deploy/`、`docs/`）。

```bash
ls /srv/yangyuanhui-src
# 应看到 api web scripts deploy docs index.html
```

---

## 第 1 步：宝塔开通 MySQL（你要手动做的）

1. 登录宝塔面板 → 左侧 **数据库** → **添加数据库**
2. 填写：
   - 数据库名：`yangyuanhui`
   - 用户名：`yyh`（可自定义，记住即可）
   - 密码：点生成强密码，**复制保存好**
   - 访问权限：**本地访问 / 127.0.0.1**（⚠️ 不要选"所有人"）
   - 字符集：`utf8mb4`
3. 提交。

> ⚠️ **3306 端口不要对外开放**。应用和数据库在同一台服务器，走 127.0.0.1 即可。

验证（宝塔终端或 SSH）：
```bash
mysql -uyyh -p -h127.0.0.1 yangyuanhui -e "SELECT 1;"
# 输入密码，返回 1 即成功
```

---

## 第 2 步：安装依赖环境（如果宝塔还没装）

宝塔通常已自带 Nginx。确认 Node.js 是 22 或 24：

```bash
node -v
# 若低于 22，在宝塔「软件商店」安装 Node.js 22
```

确认有 `node`、`npm`、`mysql` 命令。

---

## 第 3 步：部署应用（构建 + 启动）

```bash
sudo bash /srv/yangyuanhui-src/scripts/deploy.sh
```

这个脚本会：构建前后端 → 建目录 → 发布产物 → 启动 systemd 服务。
**它不再需要你填数据库信息，也不建表**——这些都在下一步网页里做。

---

## 第 4 步：配置 systemd（让后端常驻）

```bash
sudo cp /srv/yangyuanhui-src/deploy/yangyuanhui.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now yangyuanhui
sudo journalctl -u yangyuanhui -n 30    # 看日志
```

此时后端已启动，但处于「未安装」状态（因为你还没告诉它数据库在哪）。验证：

```bash
curl http://127.0.0.1:3000/api/setup/status
# 应返回 {"installed":false,...} —— 正常，下一步去网页装
```

---

## 第 5 步：网页安装向导（重点，一键完成）

> **前置：先让浏览器能打开前端。** 请先做第 6 步里 Nginx 配置的**前半段**（`cp` / `sed` / `ln` / `nginx -t` / `reload`），**先让 `http` 通即可**；HTTPS 证书（certbot）留到装完向导后再补。
> 临时方案：也可以在 `web/dist` 目录用 `npx vite preview --port 5173 --host 0.0.0.0` 起前端，访问 `http://服务器IP:5173/setup`（此时 API 请求会打到同机 3000，需 Nginx 反代或前端配代理）。推荐还是先配 Nginx。

HTTP 通了之后，访问 **`http://你的域名/setup`**（装好证书后改用 `https`）。你会看到 6 步向导：

1. **欢迎** → 点「开始配置」
2. **连接数据库** → 填第 1 步的信息：
   - 地址 `127.0.0.1`、端口 `3306`、用户名 `yyh`、密码、库名 `yangyuanhui`
   - 先点「**测试连接**」，看到「连接成功」再点下一步
   - （若库还没建，勾"数据库不存在时自动创建"）
3. **管理员** → 设账号（默认 admin）、显示名、初始密码（至少 8 位）
4. **品牌** → 平台名称（默认"养元汇"）
5. **安装** → 系统自动：建 13 张表 → 初始化数据 → 生成加密密钥 → 建超管 → 写入 `data/install.json`
6. **完成** → **立刻复制保存显示的管理员账号密码**（只显示一次）

安装向导会把配置写到 `/opt/yangyuanhui/api/data/install.json`（权限 600），**立即生效，无需手动改 .env**。

验证：
```bash
curl http://127.0.0.1:3000/api/setup/status
# 应返回 {"installed":true,...}
mysql -uyyh -p -h127.0.0.1 yangyuanhui -e "SHOW TABLES;"
# 应看到 13 张表（含 store_feishu_bindings）
```

> 🔴 **安装向导生成的 3 个密钥存在 install.json 里**（JWT / 加密 / pepper）。**务必备份这个文件**——丢失后所有加密数据无法解开，不可逆。定时备份脚本已包含它。

---

## 第 6 步：配置 Nginx + HTTPS

```bash
sudo cp /srv/yangyuanhui-src/deploy/nginx.conf /etc/nginx/sites-available/yyh
sudo sed -i 's/your-domain.com/你的域名/g' /etc/nginx/sites-available/yyh
sudo ln -sf /etc/nginx/sites-available/yyh /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d 你的域名
```

浏览器打开 `https://你的域名/setup` 完成后，用第 5 步账号登录。首次强制改密。

---

## 第 7 步：设置定时备份

```bash
crontab -e
# 末尾加一行（每天凌晨 2 点备份系统库 + install.json）：
0 2 * * * bash /opt/yangyuanhui/scripts/backup.sh
```

## 常见问题

| 现象 | 排查 |
|---|---|
| 安装向导测试连接失败 | 确认数据库账号密码对、库名对、MySQL 在跑：`systemctl status mysql` |
| 提示"无 CREATE 权限" | 宝塔建库时账号权限不足；可提前手动建库，不勾"自动创建" |
| 安装后 health 返回 db:error | 检查 `data/install.json` 里的 DB_* 是否正确 |
| 打开页面 404 | Nginx `try_files $uri $uri/ /index.html` 是否生效 |
| 登录报 500 | `journalctl -u yangyuanhui -n 50`，多半是 install.json 密钥损坏 |
| 忘记管理员密码 | 需清库重装：删 install.json、删库重建，再走安装向导 |

完成后把验收结果告诉我，确认无误再进入**阶段 2：改密/用户管理 + 飞书读写打通**（单公司模型，无多租户）。

## 附：为什么数据库配置在网页填，而不是 .env？

传统做法把 DB 配置写 `.env`，但那需要手动改文件。现在改成网页安装向导：
- 应用启动时用占位配置（不真的连库），所以**没配库也能起来**
- 你在网页填完 → 后端用临时连接测试并建表 → 写 `data/install.json` → 重建连接池，**立即生效**
- 密钥也由系统自动生成，不用你敲 `openssl`
- `install.json` 会被定时备份；重启后自动读取，配置保持

这是 WordPress 这类系统成熟的安装模式。对外的只有 Nginx；`install.json` 和 3306 端口都不暴露公网。
