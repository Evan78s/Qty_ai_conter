# 安装清单 · 照着敲（阿里云 + 宝塔 + MySQL + 私有 GitHub 仓库）

> 目标：把「鵲太醫 AI 运营工作台」部署到你自己的服务器。数据库连接、建表、建管理员全部在网页后台一键完成。
> 全程你在自己服务器操作。按顺序执行即可，命令可直接复制。

---

## 第 0 步：准备环境

1. 宝塔面板已装好 **MySQL**（你说已装好）和 **Nginx**。
2. 确认 Node.js ≥ 22：
   ```bash
   node -v    # 若低于 22，宝塔软件商店装 Node.js 22
   npm -v
   ```
3. 确认 `git`、`mysql` 命令可用。

---

## 第 1 步：宝塔建数据库

1. 宝塔 → **数据库** → **添加数据库**：
   - 数据库名：`yangyuanhui`
   - 用户名：`yyh`，密码点生成并**复制保存**
   - 访问权限：**本地访问 / 127.0.0.1**（⚠️ 不要选"所有人"）
   - 字符集：`utf8mb4`
2. 验证（宝塔终端或 SSH）：
   ```bash
   mysql -uyyh -p -h127.0.0.1 yangyuanhui -e "SELECT 1;"
   ```
   返回 `1` 即成功。⚠️ 3306 不要开放公网。

---

## 第 2 步：拉取代码（私有仓库）

仓库是私有的，服务器要先用 SSH key 获得读取权限。

### 2.1 服务器生成一把专用 key

```bash
ssh-keygen -t ed25519 -C "server-deploy" -f ~/.ssh/qty_ai_deploy -N ""
cat ~/.ssh/qty_ai_deploy.pub
```

### 2.2 把输出的公钥加到 GitHub

- 打开 https://github.com/Evan78s/Qty_ai_conter → **Settings → Deploy keys → Add deploy key**
- Title 填 `server-read`，Key 粘贴刚才那串公钥
- **不用勾 Allow write access**（服务器只需读取；写权限是你本地那把 key）
- Add key

### 2.3 配置 SSH 别名并克隆

```bash
cat >> ~/.ssh/config <<'EOF'
Host qty-github
  HostName github.com
  User git
  IdentityFile ~/.ssh/qty_ai_deploy
EOF
chmod 600 ~/.ssh/config

ssh -T qty-github    # 显示 Hi Evan78s/Qty_ai_conter! 即成功

git clone qty-github:Evan78s/Qty_ai_conter.git /srv/yangyuanhui-src
cd /srv/yangyuanhui-src
ls    # 应看到 api web scripts deploy docs index.html
```

> 以后更新代码：`cd /srv/yangyuanhui-src && git pull`，再重跑第 3、4 步即可。

---

## 第 3 步：部署应用（构建 + 发布）

```bash
sudo bash /srv/yangyuanhui-src/scripts/deploy.sh
```

这个脚本会：构建前后端 → 建目录 → 发布产物 → 准备数据目录。
**它不建表、不连库**——这些在第 5 步网页向导里做。

---

## 第 4 步：配置 systemd（后端常驻）+ 先让 HTTP 通

### 4.1 systemd

```bash
sudo cp /srv/yangyuanhui-src/deploy/yangyuanhui.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now yangyuanhui
sudo journalctl -u yangyuanhui -n 30
# 看到 "running on http://127.0.0.1:3000" 即正常
```

验证未安装状态：
```bash
curl http://127.0.0.1:3000/api/setup/status
# 应返回 {"installed":false,...} —— 正常
```

### 4.2 先配一个 HTTP 版 Nginx（让浏览器能打开，证书之后再上）

```bash
sudo tee /etc/nginx/sites-available/yyh > /dev/null <<'EOF'
server {
    listen 80;
    server_name 你的域名;
    client_max_body_size 20m;
    location / {
        root /opt/yangyuanhui/frontend/dist;
        try_files $uri $uri/ /index.html;
    }
    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    location /files/ {
        alias /opt/yangyuanhui/data/files/;
    }
}
EOF
sudo ln -sf /etc/nginx/sites-available/yyh /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

> 把 `你的域名` 换成真实域名；没有域名先用服务器 IP 也行。

## 第 5 步：网页安装向导（只做一次）

浏览器打开 **`http://你的域名/setup`**，看到 6 步向导：

1. **欢迎** → 开始配置
2. **连接数据库** → 填：地址 `127.0.0.1`、端口 `3306`、用户名 `yyh`、密码、库名 `yangyuanhui`
   - 先点「**测试连接**」，成功再下一步
3. **管理员** → 账号（默认 admin）、显示名、初始密码（≥8 位）
4. **品牌** → 平台名称默认「鵲太醫」，logo 已内置
5. **安装** → 自动建 13 张表 → 初始化数据 → 生成密钥 → 建管理员 → 写 `data/install.json`
6. **完成** → **立刻复制保存管理员账号密码**（只显示一次）

验证：
```bash
curl http://127.0.0.1:3000/api/setup/status    # installed:true
```

> 🔴 安装向导生成的 3 个密钥存在 `/opt/yangyuanhui/api/data/install.json`（权限 600）。

## 第 6 步：上 HTTPS（推荐）

```bash
sudo certbot --nginx -d 你的域名
```

certbot 会把第 4.2 步的 HTTP 配置自动升级为 HTTPS（带 80→443 跳转）。
之后浏览器用 `https://你的域名` 访问。

## 常见问题

| 现象 | 排查 |
|---|---|
| `git clone` 报 Permission denied | Deploy key 没加或没生效；`ssh -T qty-github` 重测 |
| 安装向导测试连接失败 | 账号密码/库名对不对、MySQL 在跑：`systemctl status mysql` |
| 提示"无 CREATE 权限" | 宝塔建库时权限不足；提前手动建库，不勾"自动创建" |
| 打开页面 404 | Nginx `try_files $uri $uri/ /index.html` 是否生效 |
| 登录报 500 | `journalctl -u yangyuanhui -n 50`，多半 install.json 密钥损坏 |
| 忘记管理员密码 | 删 `install.json` + 清库重建，重新走向导（会丢数据，谨慎） |
| 升级后改了东西没生效 | `cd /srv/yangyuanhui-src && git pull` 后重跑第 3、4 步并 `systemctl restart yangyuanhui` |

## 附：数据库配置为什么在网页填而不是 .env？

传统做法把 DB 配置写 `.env`，需要手动改文件。现在用网页安装向导：
- 应用启动用占位配置（不真连库），所以**没配库也能起来**
- 网页填完 → 后端测试连接并建表 → 写 `data/install.json` → 重建连接池，**立即生效**
- 密钥由系统自动生成，不用手敲 `openssl`
- `install.json` 会被定时备份；重启自动读取，配置保持

对外的只有 Nginx；`install.json` 和 3306 都不暴露公网。
