## 1. 首次登录与改密

1. 浏览器打开 `https://你的域名`，自动进入登录页。
2. 输入**安装时设置的管理员账号和初始密码**（不是演示账号，是你自己在 `/setup` 里填的）。
3. 首次登录会**强制弹出「修改密码」窗口**：
   - 原密码：填初始密码
   - 新密码：至少 8 位，建议字母+数字+符号
   - 确认新密码：再输一遍
   - 点「确认修改」→ 系统自动退出 → 用新密码重新登录。

> 忘记密码？见文末[常见问题](#10-常见问题)。

## 2. 界面总览与门店切换

系统为连锁结构设计，**几乎所有数据都可以按门店查看**，切换入口有两处（联动同一状态）：

- 左侧栏「当前门店范围」下拉框
- 顶部标题栏右侧的下拉框

选项为「全部门店」或某一家分店（总店 / 静安店 / 浦东店）。切换后总览、看板等页面数据会实时重绘。

**左侧菜单分组：**

| 分组 | 页面 |
|---|---|
| 工作台 | 总览驾驶舱 |
| 店铺管理 | 店铺业绩看板、每日对账录入、门店档案 |
| 境外投流 | 境外推广看板、AI 客服接待、投流账户管理 |
| 自媒体 AI | 自媒体工作台、素材生成工坊 |
| 系统设置 | 权限管理、系统设置、AI 模型与密钥、小程序预览 |

> 菜单按角色权限显示：员工/店长看不到「系统设置」等无权限页面。侧栏底部显示版本号、版本类型和作者。

## 3. 工作台

### 总览驾驶舱（首页 `/`）
- **核心指标卡**：总营业额、耗卡金额、充值金额、到店人次（带涨跌标签）。
- **营业额趋势图**：右上角切换「近 7 天 / 近 30 天」。
- **客户来源构成**：环形图。
- **待办提醒**：对账录入、AI 客服、投流优化、内容发布——**整行可点击**，直接跳转到对应页面。
- **导出日报**：点击弹出导出提示。
- **AI 经营解读**：点击右侧滑出抽屉，显示经营摘要与建议，点「知道了」关闭。

## 4. 店铺管理

### 4.1 店铺业绩看板（`/store`）
- 顶部切换「日 / 周 / 月」维度，指标随维度换算。
- 图表：营业额与耗卡趋势、项目营收占比、客户来源渠道。
- 门店对比区：下拉切换对比指标（总营业额 / 耗卡金额 / 充值金额 / 到店人次）。
- **AI 对账核对**：点开抽屉显示核对结论，点「确认写入飞书」写入（当前为演示）。

### 4.2 每日对账录入（`/reconcile`)
标准流程：**录入 → AI 核对 → 人工确认 → 写入飞书**。
1. 选「对账日期」。
2. 在文本框**粘贴收银系统对账文本**，或点「上传截图」上传结算图。
3. 点「开始 AI 核对」→ 右侧显示字段级核对结果（一致 / 不一致）。
4. 核对无误后点「确认并写入飞书」。
5. 底部「飞书数据同步记录」表显示已写入的历史记录。

### 4.3 门店档案（`/storefile`)
- 门店卡片：可「编辑」「员工管理」。
- 项目价目表：项目名称 / 类别 / 售价 / 耗卡价 / 时长 / 状态，可「新增项目」。
- 页头「新增门店」添加分店。

## 5. 境外投流

### 5.1 境外推广看板（`/ads`)
- 切换平台「Meta / Google Ads」，数据随之重绘。
- 指标：投流花费、曝光量、点击率 CTR、转化 / ROAS。
- 图表：花费与转化趋势、投放国家表现、转化漏斗。
- 表格「广告系列表现」，ROAS 按阈值着色。
- **AI 分析**：抽屉列出异常与优化建议，可「生成日报写飞书」。

### 5.2 投流账户管理（`/adsaccount`)
- 已列出 Meta（Business Manager）、Google Ads（MCC）账户卡。
- 操作：「绑定账户」「同步数据」「授权管理」（OAuth 授权，预留接口）。

### 5.3 AI 客服接待（`/service`)
四个标签页：
- **待人工接待**：AI 无法解决的会话队列，点行内「回复」→ 输入回复内容 →「发送回复」（同步飞书）。
- **知识库**：标准问法 / 答案 / 标签 / 命中次数。可「新增知识条目」「编辑」「同步飞书」。
- **AI 回复记录**：历史自动回复明细。
- **飞书推送配置**：设置推送时间、推送内容、**飞书群机器人 Webhook**、目标群，点「保存配置」，可用「发送测试」验证。

## 6. 自媒体 AI

### 6.1 自媒体工作台（`/social`)
小红书优先，三个标签页：
- **账号监控**：粉丝总量、净增、互动率、爆款数，粉丝增长趋势图。
- **发布计划**：内容日历，可「新建内容」。
- **互动回复**：用户评论/私信 + AI 建议回复，行内「发送」「编辑」。
- 页头「创作内容」跳转素材工坊。

### 6.2 素材生成工坊（`/material`)
1. 选素材类型「图文笔记 / 短视频」。
2. 填「主题 / 提示词」。
3. 选视频供应商（选短视频时）：方舟 Seedance 2.0 / 即梦 / 可灵。
4. 点「生成素材」→ 在素材库查看结果。
5. Skill 管理区显示已安装技能及状态。

## 7. 系统设置（重点，走真实后端）

### 7.1 飞书授权（标签页一）
> 飞书是业务数据库，必须先授权才能把门店数据写进去。

1. 按页面「如何授权」三步：在飞书开放平台建应用 → 开通 `bitable:app` 权限 → 把应用加为各表格协作者。
2. 点「+ 添加凭证」，填写：
   - **App ID**（`cli_` 开头）
   - **App Secret**
   - **范围**：公司默认 / 门店专用
3. 保存后表格显示凭证，状态可「启用 / 停用」，行内可「编辑」「删除」。

### 7.2 门店表格绑定（标签页二）
> 每家门店一个飞书多维表格。

1. 点「+ 绑定门店」，选择门店，填写：
   - **多维表格 app_token**（`bascn` 开头）
   - **表格链接**（可选，用于「打开表格」跳转）
   - **使用凭证**
   - 8 个子表的 table_id：每日业绩、投流洞察、客服知识库、AI 回复、待人工接待、自媒体、素材、推送配置
2. 保存后行内可「编辑」「打开表格」「解绑」（解绑不删数据，数据仍在飞书）。

### 7.3 平台品牌（标签页三）
- 修改「平台名称」「Logo 文字」「Logo 图片地址（可选，带预览）」「副标题」。
- 点「保存」→ 前端立即生效。

### 7.4 数据库（标签页四）
- 只读展示：连接状态、地址、库名、用户、数据表数量及表名。
- 配置实际存放在服务器 `api/data/install.json`，此处仅查看。

### 7.5 权限管理（`/permission`)
- **新增用户**：填姓名、账号、角色（总管理员 / 店长 / 员工 / 只读审计）、可访问门店（多选）。
- **角色权限矩阵**：V 查看 / E 编辑 / A 审批 / X 导出，单元格可点切换。
- **门店管理**：添加门店、查看地址/店长/员工数。
- **审计日志**：操作记录，可「导出」。

### 7.6 AI 模型与密钥（`/aiconfig`)
- 全局默认（仅总管理员）：默认供应商、默认模型、**全局 API Key**。
- 供应商接入：DeepSeek、方舟 Agent Plan、方舟 Ark 按量、阿里百炼、自定义接口——每个可「测试连接」「配置」。
- 场景模型绑定：5 个场景（对账、投流、自媒体、客服、视频）可分别「修改」模型与温度。
- 个人自带密钥：**我的 API Key**（留空则用全局），优先级 个人 > 门店 > 全局。
- 密钥 AES-256-GCM 加密存储，前端只显示掩码。

## 8. 各端使用（PWA）

系统内置 PWA，**无需下载安装包，也无需上架应用商店**：

- **手机 / 平板**：用浏览器打开网址 → 菜单 →「添加到主屏幕」。
- **电脑**：Chrome / Edge 地址栏右侧点「安装」图标。

安装后全屏使用，界面像原生 App，且每次打开都是最新版（不缓存数据）。
> 完整体验需要 HTTPS 域名（你已配置，可用）。

## 9. 重要说明：哪些是真实数据，哪些是演示

系统按阶段交付，**当前为阶段 1**（框架 + UI 完整，真实后端能力逐步接入）：

| 模块 | 当前状态 |
|---|---|
| 登录 / 改密 / 退出 | ✅ 真实（MySQL 校验） |
| 系统初始化 `/setup` | ✅ 真实（建表 + 建管理员） |
| 系统设置（飞书凭证、门店绑定、品牌、数据库状态） | ✅ 真实（写入后端 / 数据库） |
| 门店列表 | ✅ 真实接口（部分展示字段为演示补充） |
| 总览 / 业绩看板 / 对账 / 投流 / 客服 / 自媒体 / 素材 / 权限矩阵 / 小程序预览 | ⚙️ 演示数据（界面与流程完整，数据为内置示例，操作返回演示提示） |

**这意味着**：你可以完整体验所有界面和流程；要让某个看板显示真实数据，需要接对应数据源（飞书授权、投流 OAuth、AI Key 等），这是后续阶段的工作。**品牌名、门店、账号权限等配置是真实生效的**。

> 数据源标注：境外投流、小红书等页面均带「模拟数据」标签，认证/授权后可切换真实数据。

## 10. 常见问题

| 问题 | 处理 |
|---|---|
| 打不开网页 | 确认域名解析、宝塔站点与 SSL 正常；后端 `systemctl status qty-api` 应为 active |
| `/setup` 或子页面 404 | 宝塔「网站 → 设置 → URL 重写 / 伪静态」填 `try_files $uri $uri/ /index.html;` |
| 测试连接 502 | 后端没起来：查 3000（或你改的端口）是否被占用、Nginx 反代端口是否与后端一致 |
| 忘记管理员密码 | 进数据库 `quetaiyiai` 的 `users` 表重置（密码为 bcrypt+pepper，建议重装初始化或联系维护者） |
| 飞书写入失败 | 检查凭证是否有效、`bitable:app` 权限是否开通、应用是否为表格协作者、8 个 table_id 是否填对 |
| 页面数据不刷新 | Ctrl+F5 强刷；PWA 已禁用数据缓存，每次打开取最新版 |
| 想升级到最新版 | 网站目录版：`cd /www/wwwroot/quetaiyiai-src && git pull && bash scripts/web-deploy.sh` |
